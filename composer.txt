Install PHP and Composer (Powershell)
-------------------------------------
Set-ExecutionPolicy Bypass -Scope Process -Force; [System.Net.ServicePointManager]::SecurityProtocol = [System.Net.ServicePointManager]::SecurityProtocol -bor 3072; iex ((New-Object System.Net.WebClient).DownloadString('https://php.new/install/windows/8.4'))

1. composer init -> Initialize Composer in new projct
2. composer require  {name/name} -> Adds a dependency to the projects
3. composer require --dev  {name/name} -> Adds a dev dependency to the projects
4. composer dump-autoload -o -> Autoloading
5. composer install -> Installing packages in project
6. composer remove -> Removes packages in project
7. composer updates -> Installs packages with updated version (latest).

Make Laravel Project
---------------------
laravel new {name}

Clearn Cache
---------------
php artisan config:clear
php artisan cache:clear

Migrate
----------
php artisan migrate

Run server
---------------
php artisan serve
